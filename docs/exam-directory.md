# Exam directory and availability

The directory lists exam goals separately from available practice. The twelve goals added in this release are information-only: no questions were added or assigned to them, and no full mocks or previous-year papers are represented as available. Availability and counts are calculated from the actual test catalogue, not a manually assigned popularity or coverage score.

## Research references

- [SSC examination calendar](https://ssc.gov.in/for-candidates/examination-calendar): MTS/Havaldar, CPO and Stenographer; current information should be checked with SSC.
- [SBI Careers — current openings](https://sbi.co.in/web/careers/current-openings): Junior Associate recruitment.
- [IBPS RRB notification](https://www.ibps.in/wp-content/uploads/CRP-RRBs-XV-notification.pdf): Officer Scale I and Office Assistant (Multipurpose); [IBPS Specialist Officer notification](https://www.ibps.in/wp-content/uploads/Detailed-Notification-CRP-SPL-XVI_Final_V1_30.06.2026.pdf).
- [RRB ALP notice](https://www.rrbcdg.gov.in/uploads/2026/01-ALP/012026ALP-CEN.pdf) and [RRB Technician notice](https://www.rrbcdg.gov.in/uploads/2025/02-TECH/022025-CEN_updated.pdf). Links in the app point to RRB Chandigarh's notices and remind candidates to check their regional RRB as well.
- [RPSC Rajasthan State and Subordinate Services syllabus](https://rpsc.rajasthan.gov.in/Static/Syllabus/7D943B35-2D9E-4E50-BC3E-3726268AE18B.pdf) and [RSSB](https://rssb.rajasthan.gov.in/) for Rajasthan CET.

The directory does not embed dates, vacancies, eligibility or marking rules for the new goals: these can change and should be verified against the current official notification.

## Interface research

[Testbook's public previous-paper directory](https://testbook.com/previous-year-papers) and [Oliveboard's public test-series directory](https://www.oliveboard.in/test-series/) informed the exam-first category navigation and focused practice discovery. The interface is original; those products' inventories, rankings and services are not represented as ExamEdge features. ExamEdge's PYQ library and full-mock sections remain explicitly marked as not added.
